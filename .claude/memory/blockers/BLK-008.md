# BLK-008 — Build Next cassé au prerender de /opengraph-image

| Friction                                                                                                                                                              | Cause réelle                                                                                                                                                                                                                                                                    | Solution                                                                                                                                                                                                                                                                       | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| `pnpm build` échoue à `Export encountered an error on /opengraph-image/route`, avec un `TypeError: fetch failed` dont la cause est `Error: not implemented... yet...` | Le chargement des polices utilisait le pattern `fetch(new URL('./_og-fonts/x.woff', import.meta.url))`, très répandu dans les exemples `ImageResponse`. Turbopack ne résout pas les URL `file://` — le message « not implemented... yet... » vient de son loader, pas du réseau | `readFile(join(process.cwd(), 'src', 'app', '_og-fonts', file))` depuis `node:fs/promises`, plus `outputFileTracingIncludes` dans `next.config.ts` pour que les `.woff` atteignent le bundle serverless (le tracing automatique ne détecte pas un chemin construit au runtime) | résolu |

Le message d'erreur est trompeur à deux niveaux : il parle de `fetch` alors que rien ne part sur le réseau, et le vrai fetch de la route (celui vers Hugging Face) était protégé par un `try/catch`, ce qui a permis d'écarter rapidement la piste réseau. C'est l'absence de `try/catch` autour du chargement des polices qui a localisé le vrai coupable.
