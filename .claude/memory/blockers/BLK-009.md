# BLK-009 — og:image générée illisible : 6 tuiles superposées sur une ligne

| Friction                                                                                                                                                                                                 | Cause réelle                                                                                                                                                                                                                                                                                                                            | Solution                                                                                                                                                             | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Le build passe, le PNG sort en 1200×630 avec le bon poids — mais les 6 tuiles sont écrasées les unes sur les autres en une seule rangée, badges et prix se chevauchant, l'image est totalement illisible | Deux écarts de Satori par rapport à un navigateur, cumulés : (1) le **Fragment `<>`** qui enveloppait les deux rangées est mal aplati, les deux `div` se retrouvent fusionnés ; (2) **`flex: 1`** sur les tuiles n'attribue aucune largeur — Satori n'applique pas le raccourci comme un moteur CSS et il faut `flexBasis: 0` explicite | Fragment remplacé par un `div` en `flexDirection: column`, et `flex: 1` développé en `flexGrow: 1` + `flexBasis: 0` + `minWidth: 0`. Les deux commentés dans le code | résolu |

**Échec silencieux caractéristique** : aucune erreur, aucun warning, un PNG valide aux bonnes dimensions. Seul un regard sur l'image révèle le problème — et le layout avait pourtant été validé au navigateur sur le moodboard HTML, mesures à l'appui (83,5 px de marge haut/bas). Détecté uniquement parce qu'un build de vérification avait été lancé avec des données mockées avant livraison.

Voir aussi GLRN-293 (les écarts Satori/navigateur) et GLRN-296 (vérifier le rendu réel) en mémoire globale.
