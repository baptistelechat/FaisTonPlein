# BLK-013 — Port 3123 en dur bloque un second preview

| Friction | Cause réelle | Solution | Statut |
| --- | --- | --- | --- |
| `preview_start` de la configuration `video` a échoué : port 3123 occupé par le serveur d'une autre session. | `--port 3123` était codé en dur dans `.claude/launch.json`, alors que le Studio n'a besoin d'aucun port précis. | `--port` retiré, `"autoPort": true` ajouté, et `Config.setStudioPort(Number(process.env.PORT))` dans `video/remotion.config.ts`. Le Studio a redémarré, sur 3123 libéré entre-temps : le cas « autre port » n'a pas été observé. | résolu |
