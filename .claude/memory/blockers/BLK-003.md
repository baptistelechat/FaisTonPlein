# BLK-003 — Téléchargements cache sans AbortController (composant démonté)

| Friction                                                                                                                                                         | Cause réelle                                                                      | Solution                                                                                          | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------ |
| Si l'utilisateur change de zone pendant un téléchargement en arrière-plan, `cacheInBackground` peut appeler `registerFileBuffer` après le démontage du composant | Pas d'`AbortController` dans `cacheInBackground` pour annuler le `fetch` en cours | Ajouter un `AbortController` dans `useDeptCache.ts:35`, annulé au démontage / changement de rayon | ouvert |

Identifié comme dette technique active en rétrospective Epic 4 (item W2, priorité haute) — pas encore corrigé.
