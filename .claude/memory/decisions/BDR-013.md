# BDR-013 — Totem des prix nationaux : desktop uniquement, logique partagée avec l'og:image

| Décision | Pourquoi | Alternatives considérées | Statut |
| -------- | -------- | ------------------------ | ------ |
| Un totem en colonne (logo, 6 cartes de prix moyens avec évolution sur 21 jours, bouton d'installation) affiché en haut à droite de la carte sur desktop. Le calcul moyennes + deltas vit dans `src/lib/nationalPrices.ts` (`computeNationalPrices`), partagé avec `opengraph-image.tsx` ; la donnée vient de `metadata.json` via le hook `useNationalPrices` (un seul fetch par page) | Permet de se comparer à la moyenne nationale en continu, avec exactement les mêmes chiffres et seuils que la carte de partage (21 jours visés, 7 jours minimum, `=` si stable). Le hook est indépendant de la géolocalisation : le totem s'affiche sans attendre les stations | **Version mobile** : d'abord un chip avec le seul carburant sélectionné, testé puis retiré, car il occupait trop de place au-dessus du drawer. **Dupliquer le calcul** dans un composant client : deux sources de vérité à garder synchronisées | actif |
