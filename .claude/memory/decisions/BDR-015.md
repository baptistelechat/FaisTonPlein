# BDR-015 — Totem desktop : le header réserve sa place, masqué sous `@2xl`

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Pourquoi                                                                                                                                                                                                                                 | Alternatives considérées                                                                                                                                                                                                    | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Dans `DesktopLayout.tsx`, la zone carte est un `@container` Tailwind 4. Au-dessus de `@2xl` (672px de largeur de carte), le header flottant (recherche + carburants) prend `pr-66` (24 + 224 + 16 px = largeur du totem + marges) : la barre de recherche se recentre dans l'espace restant et rétrécit, donc n'est jamais recouverte. En dessous de `@2xl`, le totem est masqué (`hidden @2xl:flex`) faute de place. Le bouton d'installation reste visible | Le chevauchement dépendait de la largeur de la carte (viewport − sidebar w-96), pas du viewport : une container query est plus fiable qu'une media query. Le totem garde sa place fixe en haut à droite, c'est la recherche qui s'adapte | **Barre horizontale minimaliste en bas de carte** (`NationalPriceTotemBar`) : construite puis abandonnée à la demande de l'utilisateur, deux totems à maintenir. **Media query viewport** : ignore la largeur de la sidebar | actif  |
