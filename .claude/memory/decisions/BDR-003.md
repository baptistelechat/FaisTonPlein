# BDR-003 — Stack analytics retenue : PostHog Cloud EU + Uptime Kuma

| Décision                                                                                                                          | Pourquoi                                                                                                                                                                                                                                   | Alternatives considérées                                                  | Statut |
| --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- | ------ |
| PostHog Cloud EU (analytics + error tracking + Core Web Vitals) + Uptime Kuma existant amélioré avec un monitor sur `/api/health` | Le RPi n'est pas exposable publiquement (pas de Tailscale public) → self-hosting impossible → un seul outil cloud EU doit couvrir analytics ET error tracking. PostHog est le seul à couvrir les deux sans cookie et RGPD-safe (EU-hosted) | Plausible/Umami (pas d'error tracking), self-hosting (network impossible) | actif  |

Issu de la session de brainstorming BMAD du 2026-04-22 (Question Storming + Role Playing + Six Thinking Hats). Events prioritaires identifiés : `navigation_launched` (clic Maps/Waze = métrique de conversion #1), `mode_selected`, `fuel_selected`, `pwa_vs_web`, `geoloc_granted`. Route `/api/health` expose `{ lastETLUpdate, errorRateLast30min, stationsCount }` pour qu'Uptime Kuma détecte les dégradations silencieuses (ETL périmé) et pas seulement le "service up/down".

Pas de bannière de consentement RGPD requise (sans cookie, sans PII, EU-hosted) mais une page `/confidentialite` documentant la collecte reste prévue (P3).
