# BDR-001 — Cache départemental : IndexedDB plutôt qu'OPFS

| Décision                                                             | Pourquoi                                                                                                      | Alternatives considérées          | Statut |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | --------------------------------- | ------ |
| Cache transparent des fichiers Parquet par département via IndexedDB | Support navigateur plus large qu'OPFS, API bien connue, suffisant pour des fichiers Parquet de taille modérée | OPFS (Origin Private File System) | actif  |

Comparatif documenté dans les Dev Notes de US-04-01 avant toute implémentation — action item de l'Epic 3 ("valider l'approche technique avant d'implémenter") appliqué avec succès. Cache couvre tout `departmentsToLoad` (pas seulement le département sélectionné), 2h de validité, téléchargement en arrière-plan, progression visible uniquement dans les Réglages.
