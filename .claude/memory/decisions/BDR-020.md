# BDR-020 — Vidéos promo dans `brag-output/`, sources et captures versionnées

| Décision | Pourquoi | Alternatives considérées | Statut |
| --- | --- | --- | --- |
| Les vidéos promo vivent dans `brag-output/` (dossier fixe, sans horodatage). Sont versionnés : les storyboards `work/0*.html`, le kit, `theme.js`, `shots/` et les vignettes. Sont ignorés : `work/node_modules/`, `work/frames*/`, `work/stills*`, `*.mp4`. Le pipeline est HTML + Playwright + ffmpeg, pas Remotion. | Baptiste veut pouvoir re-rendre une vidéo depuis un autre PC sans recapturer (donc avec les mêmes chiffres) ; les MP4 et les images temporaires sont lourds et régénérables. Il a choisi de rester sur le pipeline qui a produit le style validé. | Dossier horodaté à chaque lancement (comportement par défaut de `/brag`) ; tout `work/` ignoré ; portage dans le dossier Remotion `video/` (écarté : reviendrait à refaire la DA). | actif |
