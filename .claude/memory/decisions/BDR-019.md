# BDR-019 — Projet Remotion isolé dans video/

| Décision | Pourquoi | Alternatives considérées | Statut |
| --- | --- | --- | --- |
| Les vidéos promo vivent dans `video/`, avec leur propre `package.json`, hors du workspace pnpm (`--ignore-workspace`), exclues du `tsconfig.json` et de l'ESLint racine. Structure : `src/kit/` partagé (thème, composants, bruitages, musique) + `src/videos/<slug>/` par vidéo. La logique de l'app est réutilisée via l'alias `@` → `../src`. | Rattacher `video/` au workspace ferait installer Remotion à chaque déploiement Vercel ; sans exclusion, le build Next tente de typer le code Remotion. Le kit partagé garantit le même style d'une vidéo à l'autre. | Ajouter `video` au workspace pnpm ; installer Remotion à la racine ; recopier la logique de prix au lieu de l'alias. | actif |
