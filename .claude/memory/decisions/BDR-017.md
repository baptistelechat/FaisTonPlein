# BDR-017 — Skill remotion-short pour rejouer le flux vidéo

| Décision | Pourquoi | Alternatives considérées | Statut |
| --- | --- | --- | --- |
| Le flux est formalisé dans le skill `remotion-short` (`~/.claude/skills/`) : contexte → Rodin et tableau d'accroches → accord → chiffres réels → code avec les skills Remotion → bruitages uisfx → musique libre par API → preview, rendu, journal `video/VIDEOS.md`. Les sélecteurs `sfxPack`, `music` et `musicVolume` sont obligatoires dans l'inspecteur du Studio. Le skill installe Remotion si `video/` n'existe pas. | Baptiste veut relancer le skill et retrouver ses choix sans les redonner ; `video/VIDEOS.md` garde les choix du projet et les accroches en réserve. | Refaire le flux à la main à chaque vidéo ; un skill limité à FaisTonPlein. | actif |
