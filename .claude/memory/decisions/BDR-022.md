# BDR-022 — Textes de publication : récit long, « nous », gratuit et sans pub

| Décision                                                                                                                                                                                                                                                                                                                                                                | Pourquoi                                                                                                                                          | Alternatives considérées                                                                    | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | ------ |
| Chaque texte de `brag-output/share-copy.txt` garde l'accroche chiffrée en première ligne, puis raconte le problème avant de montrer l'app. Le texte du lancement présente le projet : source open data, parcours en trois gestes, liste des atouts, slogan de fin. On écrit « nous », jamais « je ». « Gratuit, et sans pub » est une affirmation validée par Baptiste. | Les textes de deux lignes ne présentaient pas le projet, surtout celui du lancement.
