# LRN-012 — Overlay flottant dépendant d'une zone à largeur variable : container query, pas media query

| Pattern observé                                                                                                                                    | Contexte                                                                                                              | Application future                                                                                                                                                                                                                           |
| -------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un chevauchement entre overlays (totem / barre de recherche) dépendait de la largeur de la zone carte (viewport − sidebar `w-96`), pas du viewport | Desktop layout avec sidebar fixe : une media query sur le viewport aurait un seuil décalé de la largeur de la sidebar | Mettre `@container` sur la zone porteuse et utiliser `@2xl:`/`@5xl:`. Calculer le seuil géométrique (largeurs + marges) puis viser une marge de sécurité. Préférer réserver la place (`pr-66`) plutôt que déplacer ou dupliquer un composant |
