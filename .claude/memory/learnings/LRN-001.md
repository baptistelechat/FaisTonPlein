# LRN-001 — Instance DuckDB-WASM dédiée par département + retry évite les crashs

| Pattern observé                                                                                                                                                  | Contexte                                                                             | Application future                                                                                                               |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| Réutiliser une même instance DuckDB-WASM pour traiter plusieurs départements en rafale provoque un crash ("is a directory") sur certains fichiers (ex : dept 62) | Rencontré lors du script de rolling cache qui traite tous les départements en boucle | Instancier un DuckDB frais par fichier/département traité + wrapper avec retry plutôt que de partager une connexion longue durée |
