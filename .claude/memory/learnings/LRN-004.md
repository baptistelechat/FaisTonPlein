# LRN-004 — Un action item de rétro reporté sans décision sur 3 epics devient du bruit

| Pattern observé                                                                                                                        | Contexte                                                                         | Application future                                                                                                                                                                    |
| -------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| L'item "Monitoring ETL" a été reporté silencieusement de rétro en rétro depuis l'Epic 0 (5 epics consécutifs) sans jamais être tranché | Rétrospective Epic 4 — le report continu diluait la crédibilité des action items | Règle des 3 epics : tout action item non adressé sur 3 epics consécutifs doit faire l'objet d'une décision explicite (adresser ou clore) — le report silencieux n'est plus acceptable |
