# LRN-017 — Le scanner de liens Meta crée des visites et des erreurs WebGL

| Pattern observé                                                                                                                                                                                             | Contexte                                                                                                                                                               | Application future                                                                                                                                                      |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Quand un lien est publié sur Instagram ou Facebook, Meta le charge dans un Chrome sans carte graphique. La page s'exécute, PostHog compte une visite, et MapLibre lève « Could not create a WebGL context » | Le 2026-10-08 vers 19:47, trois `$exception` de type `react_render` en deux minutes, juste après la mise en ligne d'un lien. Baptiste ne reconnaissait pas ces visites | Avant de traiter une erreur WebGL comme un bug, regarder la signature ci-dessous. Après chaque publication sur Meta, s'attendre à quelques visites et erreurs parasites |

**Signature du robot :**

- écran 2000 × 2000 px, fenêtre 1050 × 1893
- géolocalisation dans une ville à datacenter Meta : Gallatin, Springfield (États-Unis), Clonee (Irlande)
- referrer `https://www.facebook.com/` et `fbclid` dans l'URL
- Chrome sur Windows, versions variables (74 et 139 relevées)

**Non fait :** ces visites ne sont pas filtrées dans PostHog. Piste proposée et laissée à Baptiste : exclure `Screen width = 2000` dans le filtre « Internal and test users », qui est un réglage du projet partagé avec ifecho ([BDR-005](../decisions/BDR-005.md)).
