# LRN-016 — Le lanceur de preview peut résoudre un autre pnpm

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| Une configuration `.claude/launch.json` lancée avec `pnpm` a utilisé pnpm 12 (winget) au lieu du 9.9 du terminal : réinstallation des `node_modules` racine et ajout d'un bloc `allowBuilds` dans `pnpm-workspace.yaml`. | Lancement du studio Remotion via `pnpm --dir video exec`, même avec `--ignore-workspace`. | Pour un sous-projet hors workspace, lancer avec `npm --prefix <dossier> run <script>`. Après un incident : retirer le bloc ajouté, `pnpm install --frozen-lockfile` avec le bon pnpm, puis rebuild. |
