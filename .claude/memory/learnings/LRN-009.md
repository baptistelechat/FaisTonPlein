# LRN-009 — Une instance self-hosted à côté d'un déploiement cloud est un angle mort de diagnostic monitoring

| Pattern observé                                                                                                                                                                                                                                                                                                      | Contexte                                                                                                                                                                                                                              | Application future                                                                                                                                                                                                                                                                                                                                                                                                   |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Une alerte de monitoring sur une route publique (ex. `/api/health`) était diagnostiquée uniquement côté code/Vercel, alors qu'une deuxième instance self-hosted (RPi via `pm2`, sans CI/CD) servait aussi cette route avec un code 24 commits en retard — antérieur même à la création de la route, donc 404 garanti | [LRN-007](../learnings/LRN-007.md) — le RPi `fais-ton-plein` (`pm2: faistonplein`) tournait depuis avril sans jamais avoir reçu les commits suivants, personne n'ayant de rappel automatique pour ça (pas d'auto-deploy comme Vercel) | Avant de diagnostiquer une alerte de monitoring qui touche une route publique, lister TOUTES les instances qui la servent réellement (pas seulement le déploiement cloud "officiel"), et vérifier leur drift git (`git log HEAD..origin/main`) sur chacune — un self-hosted sans auto-deploy peut driver silencieusement pendant des mois et devenir la vraie source d'une erreur qu'on attribuerait à tort au cloud |
