# LRN-010 — Le wrapper `docker-monitor` du NAS est NOPASSWD seulement pour `ps/stats/logs/inspect/version/images`

| Pattern observé                                                                                                                                                                                                   | Contexte                                                                                                                                                                                                                                                                                                                                                               | Application future                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Une tentative d'audit SQLite readonly sur `kuma.db` (pattern documenté par GLRN-265 en mémoire globale) via `docker exec uptime-kuma sqlite3 ...` a échoué en SSH non-interactif : `sudo: a password is required` | Le sudoers NOPASSWD du NAS ne couvre que le wrapper sécurisé `/usr/local/bin/docker-monitor` (commandes `ps`, `stats`, `logs`, `inspect`, `version`, `images`) — un `docker exec` brut via le binaire complet (`/var/packages/ContainerManager/target/usr/bin/docker`) n'est pas dans ce périmètre, même pour une commande en lecture seule comme `sqlite3 ... SELECT` | Pour un futur audit readonly nécessitant `docker exec` (SQL direct sur `kuma.db` ou autre), soit demander à Baptiste de lancer la commande lui-même en session interactive, soit lui proposer d'étendre le sudoers NOPASSWD pour un `docker exec <container> sqlite3 -readonly ...` scopé — ne pas retenter la commande brute en boucle, ce n'est pas un problème réseau mais un périmètre sudoers volontairement restreint |
