# LRN-014 — Schéma Zod = sélecteurs dans le Studio Remotion

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| Un `schema` Zod sur `<Composition>` fait apparaître chaque `z.enum` en liste déroulante et chaque `z.number().min().max().step()` en réglage dans « Default Props ». Le Studio écrit la valeur choisie dans `Root.tsx`. Un `<Audio>` accepte une URL distante si le serveur autorise le CORS. | Sélecteurs `sfxPack`, `music`, `musicVolume` ; aperçus Jamendo lus à distance. La sélection n'a pas toujours pris lors d'essais automatisés. | Relire `Root.tsx` avant un rendu final ; en complément du sélecteur, rendre un extrait par variante avec `--props` pour une comparaison sûre ; recharger le Studio après une erreur de build. |
