# LRN-013 — Pièges Remotion sous Rspack

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| Avec `Config.setRspack(true)` (défaut du scaffold), l'alias se déclare via `Config.overrideRspackConfig` : `overrideWebpackConfig` est ignoré en silence. Les props d'une composition doivent être un `type` (ou `z.infer`), pas une `interface`. Un dossier de paquet bloqué par `exports` se charge avec `require.context` sur un chemin relatif vers `node_modules`. | Mise en place de `video/`, alias `@` vers `../src`, chargement des 936 sons de `uisfx`. | Vérifier par un `remotion still` dès la config posée : `tsc` passe alors que le bundler échoue. |
