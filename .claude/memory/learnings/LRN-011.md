# LRN-011 — Deux rendus de « €/L » coexistent dans le projet

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| `PriceCard` (détail station) affiche l'unité en `text-xs font-semibold opacity-70`, `StationCard` (liste) en `text-muted-foreground ml-0.5 text-xs font-normal`, imbriquée dans le span du prix | En copiant `PriceCard` pour le totem, l'utilisateur a relevé que le « €/L » n'avait pas la même graisse que dans la liste des stations | Pour un nouvel affichage de prix, suivre `StationCard` (le rendu que l'utilisateur voit à côté). Si on veut unifier, c'est `PriceCard` qui s'aligne, pas l'inverse |
