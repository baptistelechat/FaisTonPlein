# LRN-015 — Musique libre par API : ce qui marche vraiment

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| L'API Pixabay ne couvre que images et vidéos, pas la musique. Openverse (`api.openverse.org/v1/audio`) fonctionne sans clé avec filtre `license=cc0,by` et renvoie le texte d'attribution, mais ne remonte presque que du Jamendo. Jamendo affiche la licence par icônes (`icon-cc-by`…), visibles seulement dans un navigateur ; un bouton « Acquérir une licence » signale que l'artiste vend l'usage commercial. Free To Use interdit le commercial en gratuit. CC-BY-SA est à rejeter pour une vidéo. | Recherche de musique de fond pour le short. | Vérifier la licence sur la page rendue, rejeter les pistes « Acquérir une licence », garder l'attribution exacte dans `video/audio-credits.json` et la coller en description de publication. |
